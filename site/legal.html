Condiciones de uso

  • Solo información. Lo que muestra la web son estimaciones estadísticas, no certezas. Los partidos pueden acabar de cualquier forma.
  • No es un consejo de apuesta ni de inversión. Las apuestas, la quiniela, el Quinigol y la cartera «Kelly» son simuladas con dinero ficticio, para medir el modelo. La propia web muestra que las casas de apuestas aciertan más que el modelo y que lo esperable apostando es perder dinero. No se enlaza a ninguna casa de apuestas ni a Polymarket para operar.

  • Uso razonable. Puedes consultar y enlazar la web libremente. No intentes dañarla, sobrecargarla ni usarla para fines ilícitos.

Privacidad

Qué datos se recogen

Ninguno. La web es un conjunto de archivos estáticos: no hay base de datos de usuarios, no se piden correos ni nombres, no hay inicio de sesión y no se usa ninguna herramienta de analítica (ni Google Analytics ni similares). Por eso tampoco puede filtrarse ningún dato tuyo desde aquí.

Tus derechos

Como esta web no guarda datos personales, no hay datos tuyos que consultar, corregir o borrar aquí. Para lo que registren los servicios de la tabla, consulta sus políticas. Si crees que tus derechos no se respetan, puedes reclamar ante la Agencia Española de Protección de Datos.

Cookies y almacenamiento local

La web no usa cookies ni rastreadores. Solo guarda en el almacenamiento local de tu navegador:

  • theme: el modo claro u oscuro que elijas;
  • lang: el idioma que elijas (español o inglés);
  • una copia de la propia web y de sus datos (service worker), para que se abra sin conexión.

Son preferencias que pides tú y no identifican a nadie; no salen de tu navegador. Por eso no hace falta un aviso de consentimiento. Puedes borrarlas cuando quieras desde los ajustes de tu navegador («Borrar datos de sitios»).

Seguridad

No hay servidor propio ni base de datos expuesta: la web se genera con GitHub Actions y se publica como archivos estáticos. Las claves de los servicios que usa el proceso automático se guardan como secretos cifrados de GitHub y nunca se publican en la web ni en el código.
